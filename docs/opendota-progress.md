## 合格的定义

- 详情为 `game_mode=22`、`lobby_type=7`；十个不同的正整数英雄 ID、双方各五个合法槽位、布尔胜负完整。
- 版本编号 60、开始时间和时长有效，时长至少 720 秒。
- 元数据比赛 ID 相符，双方官方职责恰好各有 1～5 号位；不以 OpenDota 推断值补缺。
- 十人 `leaver_status` 都是整数 0 或 1；这允许曾断连的状态 1，不证明整场无人掉线。
- `?meta=1` 请求来源、原始响应 SHA-256、缓存、数据库和导出内容一致。

位置源是 Valve 元数据的 `lane_selection_flags`：1→1 号位、4→2 号位、2→3 号位、8→4 号位、16→5 号位。空的 6～13 队是元数据占位，跳过；缺失、多选或非单一职责不合格。该标记是官方职责记录，不能证明实际打法和站位。

最小数据保留十一个字段，双方英雄数组按 1～5 号位排序，并显式写入 `position_source=valve_metadata_lane_selection_flags`。近似分段沿用有效玩家大段位的较低中位数，同时保存已知人数。详见[采集与筛选规则](opendota-collection.md)。
